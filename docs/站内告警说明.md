# 站内告警

入口 /#/alerts，所有页面顶部显示活动告警数与未确认数。新故障或新等待预警显示10秒提示，关闭弹窗不等于确认。

故障：根据真实快照的 faulted 状态和 robot_faulted 事件建立告警。保留位置、事件序号、关联订单；不编造机械根因。确认不执行修复。点击修复通过现有 repair_robot 接口，后续快照确认状态变化后结束告警。

拥堵：机器人有任务、处于取货/送货途中，consecutive_waits 达到阈值（默认25，范围3–1000 tick）时预警。暂停时不按真实时间累计。持续等待只提醒一次，等待条件解除后结束；新一轮持续等待重新提醒。无路和封路也可能造成等待，不能直接认定碰撞或机械故障。

世界重置会结束原世界活动告警并标注重置，不假称已修复。设置阈值提高也可能结束旧预警。历史最多约200条，保留活动记录。记录仅存本浏览器 localStorage，不是服务器审计或跨设备工单。断网时显示待核实，不根据 mock 判定恢复。只有页面运行并获得状态时才检测，不提供后台值守或外部负责人通知。

验证：node --test tests/alerts.test.mjs tests/assistant.test.mjs。

全局严重标准：同时故障至少2台，或任一执行中机器人连续等待至少60 tick；没有故障持续时长规则。关闭警告同时隐藏中央面板和红光。首次加载新规则会将旧标准迁移为25/2/60，之后仍可自行调整。
